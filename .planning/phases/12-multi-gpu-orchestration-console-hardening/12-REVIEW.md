## Warnings

### WR-01: Blanket strict-xfail opens an unbounded golden-drift detection gap until the maintainer snapshot-update lands

**File:** `tests/tui/test_snapshots.py:911-970`
**Issue:** All 9 golden tests are `@pytest.mark.xfail(strict=True)` pending
the maintainer's `make snapshot-update` + D-03 review. Until that lands,
**every** SVG-render failure is absorbed into the expected-failure bucket —
including regressions that have nothing to do with the mlc nav rename (any
future quick task touching a screen, a strings constant, or styles.tcss
drifts a render and goes green-as-xfail). `strict=True` only detects the
flip direction (a test that starts PASSING after regeneration); it cannot
detect new drift while the markers are in place. The 9-step N=2 smoke and
the D-03 review gate assume the goldens still compare meaningfully.
**Fix:** Bound the window explicitly: land `make snapshot-update` + marker
removal as a gating task before the next merge wave touches any TUI screen
(or, if the window must stay open, add a dated TODO above
`_GOLDEN_REFRESH_REASON` naming the phase/task that must close it, so a
stale marker set is visible in review rather than only in pytest output).

### WR-02: `pipeline/directories_config.py` (new production module) is missing from the `make lint` lane

**File:** `Makefile:174-181`
**Issue:** The f4w quick task added `pipeline/directories_config.py` — a
stdlib-only production module imported by `pipeline/run_sweep.py:306` and
the TUI services — but no lint entry covers it: `PHASE6_SCRIPTS`,
`PHASE7_MODULES`, `PHASE8_TUI` (a `tui/` glob), `PHASE12_MODULES`, and
`QUICK_L6H_SCRIPTS` all omit it, and the lint recipe's explicit
`pipeline/` list names only `run_finetune.py`, `run_sweep.py`,
`env_smoke.py`. Every other phase-authored pipeline module joined the lane
by the documented convention ("Phase-authored/edited files whose findings
are FIXED"). `ty check` covers it (whole `pipeline/` tree), and it is
ruff-clean today (verified), but the ruff gate is blind to its future
edits — precisely the drift the gate exists to catch.
**Fix:** Add the existence-guard idiom:
```make
# Quick-task extension (261014-f4w): the directories.json startup-config
# loader joins the pipeline list (read by run_sweep.py and tui/services).
QUICK_F4W_MODULES := $(foreach s,pipeline/directories_config.py,$(if $(wildcard $(s)),$(s)))
```
and append `$(QUICK_F4W_MODULES)` to the `lint:` recipe.
