## Overview & Information Architecture

Phase 12 is the milestone-closing hardening phase. The operator's loop is
unchanged; this phase scales it out (multi-worker orchestration via CLI only,
D-01/D-07), mirrors monitor state to the team (web), and pins the canonical
screens (goldens):

```text
 CLI (run_sweep sharding, D-07 — outside this spec's UI surface)
   │ N workers × disjoint shards × CUDA_VISIBLE_DEVICES, roots …-mgpu-w{N}
   ▼
 TUI 任务监控 (slot 5, EXISTING screen)          ← delta A: zero-code N-root proof
   discovered list: default roots + [a]-attached worker roots render as plain rows
   ▼
 script/gen_progress.py (NEW, offline)           ← reads N roots via the pure scanner
   ▼
 dnallm-mark/data/progress/sweep.json (static)   ← manual/CI regeneration (D-02)
   ▼
 dnallm-mark/progress.html (NEW page)            ← the team's read-only browser view

 Textual snapshot goldens (NEW test tier)        ← 6 screens × key states ≈ 8 SVGs (D-03)
```

| Surface | Kind | Delivers |
|---------|------|----------|
| monitor screen worker-root rendering | EXISTING screen, **zero production code** | N discovered rows for worker roots (`…-mgpu-w0`) — the discovery list was built N-capable (delta A) |
| slot-4 modal focus return | EXISTING screen, **one sanctioned behavior fix** | modal dismiss → focus returns to the picker (D-12 advisory #1; delta B) |
| `progress.html` + `js/progress.js` | NEW web page | summary header (sweep name, done/total, elapsed/ETA), per-(model,task) cell table with seed columns, model/task/status filters |
| `data/progress/sweep.json` + `script/gen_progress.py` | NEW data artifact + generator | static JSON mirroring `sweep_monitor` shapes verbatim (D-02) |
| Textual SVG goldens | NEW test tier | 6 canonical screens pinned, maintainer-reviewed, CI-red on drift (TEST-01/D-03) |

**Out of scope (locked):** any new TUI orchestration screen (D-01); web
auto-refresh/polling/SSE (deferred); DDP implementation (deferred); UAT
advisories #2–5 (D-12 pool, not this phase's gate).

## TUI Deltas (the complete TUI surface change list)

### Delta A — monitor discovery rows with worker roots: ZERO production code (D-01)

**Verified against the live screen** (`tui/screens/monitor.py:1305-1345`):
`_render_discovered()` renders `Text(summary.root.name)` — the final path
component, verbatim, for every discovered root; discovery scans
`DEFAULT_OUTPUT_ROOTS` + the XDG-persisted manual roots (`monitor_roots.json`,
written by the existing `[a]` attach flow). A worker root such as
`pipeline/finetuned-mgpu-w0` therefore renders as a plain discovered row
`finetuned-mgpu-w0` with **zero code change**: no worker-specific chrome, no
glyph amendment, no new strings. `enter` attaches it; the cell table, stats,
failures, and logs rebind to that root — exactly the slot-5 attach contract.
D-01's ruling ("worker = 独立输出根, 发现列表天然 N 行, Enter 附加即视图") is
already implemented by Phase 11's N-capable design.

```text
 发现的 sweep (3) — 默认输出根 + 手动附加
   状态        输出根                    规模          进度                ETA
   ◆ ● 运行中  finetuned-mgpu-w0        3×4×3         12/36 █████·····      ≈2.1h
     ● 运行中  finetuned-mgpu-w1        3×4×3         9/36 ███·······       ≈2.4h
     ○ 已结束  finetuned-smoke          1×1×1         1/1 █                 —
```

(Wireframe delta: none — this IS the Phase-11 layout with three rows; shown
only as the acceptance proof.)

**Contract statements:**

1. Worker roots enter discovery via the EXISTING paths only: the operator
   attaches each worker root once (`[a]`; roots persist across restarts), or
   the plan's orchestrator CLI places roots under a scanned default. **No TUI
   code may special-case worker-root names** (no `mgpu-` prefix parsing in
   `tui/` — the discovery list is root-name-agnostic by design).
2. The DELTA is **test-only**: a scan/Pilot test constructs `SweepSummary`
   fixtures for roots `finetuned-mgpu-w0` / `-w1` (+ one default root) and
   asserts the discovered table renders N+1 rows with the names verbatim and
   per-row states/progress independent (worker isolation visible at a glance —
   SC2's operator view).
3. Zero new `strings.py` constants; zero `styles.tcss` changes; zero glyph
   amendments.

### Delta B — the D-12 focus-trap fix (the ONE sanctioned TUI behavior change)

11-UAT advisory #1, verbatim symptom: after the 启动门/预览 modals close on
slot 4, focus falls into a params `Input`; Escape only clears the filter, not
the input focus; digits 1–6 are eaten by the Input so navigation deadlocks;
recovery = restart. Advisory recommendation, adopted as contract: **modal
dismiss returns focus to the picker** — the behavior the filter's Enter path
already has (`tui/screens/run_config.py:1389`).

**Behavior contract:**

| # | Rule |
|---|------|
| B1 | After ANY slot-4 modal pops (preview `[p]`, choice RadioSet, launch gate, E2' typed-phrase — via `esc`, cancel, confirm, or error paths), app focus lands on `#cfg-picker` (PickerList) — never on a params Input, the filter, or nothing. |
| B2 | Immediately after a modal dismiss, digit keys 1–6 navigate (the nav shell consumes them — no Input owns them) and `space`/`m`/`/` act on the picker. This is the regression assertion, not a new binding. |
| B3 | The filter Input's existing Enter-returns-to-picker behavior is unchanged (it is the precedent, not the fix). |
| B4 | Implementation shape (plan-owned within this contract): refocus at modal-dismiss time or a screen-level resume hook — `self.query_one("#cfg-picker", PickerList).focus()` — one code site per modal family or one shared helper in `run_config.py`. NO new bindings, NO new strings, NO styles.tcss change. |
| B5 | Scope guard: advisories #2–5 (Tab-chain reachability, numerator scope, focus-region hints, `q` copy) are NOT in scope (D-12: 建议级 pool, advisory #1 only). The monitor screen's modals need no fix here (no reported trap; its modals return to tables). |

**Keymap delta: none.** No key is added, removed, or rebound. The fix changes
only the focus landing after dismiss.

**State delta (house format):**

| State | Before (bug) | After (contract) |
|-------|--------------|------------------|
| slot-4 modal dismissed | `app.focused` = params Input (or unset) — digits eaten | `app.focused` = `#cfg-picker` — digits navigate |
| E2' gate confirmed/escaped | focus lost to `#cfg-e2-input`'s screen | `#cfg-picker` focused |
| choice modal picked/escaped | focus stays on ChoiceRow chain | `#cfg-picker` focused |

**Pilot test (tier-2, `tests/tui/`):** boot slot 4 with marks → `p` + `esc` →
assert focused is picker; open a choice modal + `esc` → assert; `[enter]`
gate → `esc` → assert; then press `3` and assert the data-manager screen is
active (the deadlock is gone). Deterministic fakes, no sleeps (inherited
discipline).

## Data Contract — `dnallm-mark/data/progress/sweep.json` (verbatim from `sweep_monitor` shapes)

The JSON keys are the frozen dataclass field names of
`tui/services/sweep_monitor.py` (`SweepSummary`, `CellRow`, `CellSeed`,
`SweepStats`, `EtaEstimate`, `CurrentCell`) and its machine-string
vocabularies (`finished`/`running`/`artifacts_only`;
`completed`/`failed`/`skipped`/`running`/`queued`;
`pending`/`point`/`range`/`none`) — **the generator imports the pure scanner
and serializes its dataclasses; nothing is re-typed or renamed.** The scanner
is deliberately textual-free (its module docstring + the import-lock test),
so `script/gen_progress.py` imports it headless.

```json
{
  "version": 1,
  "generated_at": "2026-10-13T09:30:00Z",
  "sweeps": [
    {
      "root": "finetuned-mgpu-w0",
      "state": "running",
      "done": 12,
      "total": 36,
      "elapsed_seconds": 4360.0,
      "current": { "model": "plant-dnabert-6mer", "task": "GUE__emp_H3", "seed": 42 },
      "eta": { "mode": "point", "point_seconds": 7560.0, "lo_seconds": null, "hi_seconds": null },
      "state_counts": { "completed": 12, "failed": 1, "skipped": 2, "running": 1, "queued": 20 },
      "cells": [
        {
          "model": "plant-dnabert-6mer",
          "task": "GUE__emp_H3",
          "seeds": [
            { "seed": 42, "state": "running", "fraction_states": null },
            { "seed": 43, "state": "skipped",
              "fraction_states": [["frac_0.5", "completed"], ["frac_0.7", "queued"]] }
          ]
        }
      ]
    }
  ]
}
```

| Field | Type | Rules (mirror of the scanner's semantics) |
|-------|------|-------------------------------------------|
| `version` | int | `1`; bump on any breaking shape change |
| `generated_at` | string | ISO 8601 UTC, generator clock — the page renders it verbatim |
| `sweeps[].root` | string | `SweepSummary.root.name` — final path component (worker roots read `finetuned-mgpu-w0`) |
| `sweeps[].state` | string | one of `finished` / `running` / `artifacts_only` |
| `sweeps[].done` / `.total` | int \| null | `null` total = unknown → page renders `Unknown total`, empty bar, `ETA —` |
| `sweeps[].elapsed_seconds` | float \| null | `null` before the first record |
| `sweeps[].current` | object \| null | `CurrentCell` — omitted keys never fabricated |
| `sweeps[].eta` | object | `EtaEstimate` — `mode` + exactly the meaningful fields; `pending` → page renders `Estimating…`, `none` → `—` |
| `sweeps[].state_counts` | object | the five cell states → counts, generator-derived from the same pass (page summary chips) |
| `sweeps[].cells[]` | array | `CellRow` list; one entry per (model, task); `model` is the alias identity verbatim |
| `cells[].seeds[].seed/.state/fraction_states` | int / string / array \| null | `CellSeed`; unknown record statuses pass through verbatim (the scanner's honest rule — page renders the raw string in the glyph slot with the legend disclaimer) |

**Generator** — `script/gen_progress.py` (house script conventions: module
docstring with input/output/usage, `main()` with `# ===== Configuration
=====`, `json.dump(..., indent=4, ensure_ascii=False)`):

```text
python script/gen_progress.py [ROOT ...] --output dnallm-mark/data/progress/sweep.json
```

- Positional `ROOT`s: one or more sweep output roots (the multi-worker case
  passes every worker root; a merged root may be passed alongside). No
  positional args → the scanner's `DEFAULT_OUTPUT_ROOTS` (the two
  `./finetuned` resolutions).
- `--output` default `dnallm-mark/data/progress/sweep.json` (repo-relative;
  scripts are CWD-sensitive by house convention — docstring states to run
  from the repo root, the `export_runs.py` precedent).
- Tolerant per-root behavior: an unreadable root contributes a
  `state_counts`-bearing sweep only if the scanner yields one — the
  scanner's degrade-never-crash contract; a root with no artifacts is
  skipped with a `[Skip]` console line (the per-file skip precedent).
- Friendly console output with the ✅ marker (house style):
  `✅ Progress mirror written: {path} ({n} sweeps)`.
- **No `--open`, no server, no watch** — regeneration is manual/CI (D-02,
  deferred: no auto-refresh).
