## Overview & Information Architecture

Phase 11 promotes both remaining placeholder slots to real base screens under
the Phase 9 shell and closes the operator's core loop end-to-end:

```text
 compose (槽 4) ──[p]──► same-source dry-run preview ──[enter]──► 启动门
                                                                   │ env preflight (D-08)
                                                                   │ summary confirm (LNC-01)
                                                                   │ E2' typed phrase (D-02/D-07)
                                                                   ▼
                                             run_sweep.py detached subprocess (D-06)
                                                                   │ toast + auto-nav (D-13)
                                                                   ▼
 monitor (槽 5) ◄── discover / attach (D-03) ── cells · stats+ETA (D-17) ·
                    failures ──[f]── from-failures re-run (D-11) · logs ──[t]── tee tail (D-10)
```

| Surface | Kind | Delivers |
|---------|------|----------|
| `RunConfigScreen` (slot 4 运行配置) | base screen, NEW | own model/dataset pickers (D-01), full params pane (CFG-01), dirs (CFG-02), live same-source preview line + `[p]` detail (CFG-03/D-05), `[enter]` launch gates (LNC-01..03) |
| `MonitorScreen` (slot 5 任务监控) | base screen, NEW | discovered-sweeps pane (D-03), attach flow, cell-level status table (MON-01), stats line with elapsed + ETA (MON-02/D-17), failure list + gated re-run (MON-03/D-11), bounded log tail + tee (MON-04/D-10), resume recognition (MON-05) |
| `LaunchGateModal` | modal, NEW | terraform-style confirm; escalates to the E2' typed-phrase gate (D-02/D-07) |
| env-block modal | modal, NEW (ConfirmModal family) | quick-check FAIL block with verbatim reasons (D-08) |
| `ExitModal` | app-level modal, NEW | kill / detach / cancel on quit with a live sweep; default detach (D-06) |
| preview / failures / log-tail / cell-detail / attach-path modals | modal, NEW (existing families) | `[p]` dry-run detail + argv; `[f]` failure list + `[r]` re-run confirm; `[t]` log tail; `enter` cell detail; `[a]` path input |

Machine constraint (D-15): this host is dev/test only — the screen contracts
must work at smoke scale (1 model × 1 task × 1 seed × 1 epoch) and at full
E2' scale (62 × 50 × 3 = 9300 cells) without layout change; the E2' gate copy
carries the maintainer-authorization boundary on every full enumeration.

### Region contract

- **Two columns** (auto-default #1): picker column left (~56 cells at 120,
  ~38 at 80), params column right (the remainder), separated by the existing
  full-width `─` rule treatments, not borders (borders stay reserved for
  modals). Column split is a width ratio, not a spacing token.
- **Picker region** (D-01): 1-row title `模型 ({n}/{total})` or
  `数据集 ({n}/{total})` (zero-one-many counts), the 1-row filter bar (the
  selection-screen grammar verbatim: `过滤: ` label + Input + right-aligned
  `({n}/{total})`), then the SelectionList (scrolls). `m` flips the visible
  kind and the title with it (the slot-2 `m` verb, one vocabulary). Model rows
  render the `◇` custom badge (inherited vocabulary) and in-item truncation at
  the column width — the full key always in `enter` detail (the 68-char-key
  lesson). Disabled custom entries keep their `（已停用）` suffix and cannot be
  marked (never silent — the inherited warning toast).
- **Params pane** (CFG-01 exhaustive — one label row + one value row per
  field, scrolling `VerticalScroll`): `seeds` Input (default `42,43,44`),
  `PEFT` choice row (none/lora/ia3), `变体` choice row (none/head/probe/curve),
  `曲线档位` Input (`--curve` fractions, empty = off), `公平子集` Checkbox +
  path row (default `pipeline/eval_subsets.json`), `epochs 覆盖` Input,
  `effective_batch_size` Input (empty = not threaded, the child's YAML GA
  governs). Choice rows render the current value + `▾`; `enter` on a focused
  choice row opens a RadioSet modal (the preset-modal family); `enter` on a
  text row focuses its inline Input. The value `—` means absent/off (dim).
- **Derived hint lines** (dim, 1 row each, directly under their field — the
  wizard advisory pattern): PEFT alias preview
  `别名预览: {model}+lora（独立输出目录与续跑标记）` when mode ≠ none; 变体
  alias `保存名: {model}+{variant}`; the head exception note; the probe hint
  `⚠ probe 不可用: {models}（专用 loader, 冻结不生效）` — rendered when
  变体=probe and ANY picker row (not only marked rows) is in the frozen
  `PROBE_INELIGIBLE` list imported from `pipeline/run_finetune.py` (data, 9
  names, never duplicated in strings.py).
- **Dirs section** (CFG-02/D-14): a 1-row section divider `── 目录 ──` (the
  full-width `─` rule + label), then 输出根 / 数据集根 / 模型缓存 Input rows.
  Defaults are repo-relative (`./finetuned`, `./datasets`, `—（HF 默认）` =
  absence); an explicit override always threads an ABSOLUTE resolved path
  (D-14). Path advisories reuse the wizard constants (`✓ 路径存在` /
  `✗ 路径不存在（仍可继续，提交时统一校验）`); a nonexistent 输出根 parent is
  advisory-only (the sweep creates the root).
- **Preview line** (CFG-03/D-05): 1-row status line directly above the bottom
  bar, `干跑: {models} 模型 × {tasks} 任务 × {seeds} 种子 = {cells} cell`
  (+ `× {fractions} 档` when 曲线档位 is set), recomputed live in a worker on
  every selection/param change by calling the IMPORTED pure planning functions
  (`enumerate_matrix` — never a reimplementation); problems render
  `⚠ 预览校验失败 — 共 {n} 处问题：` inline-truncated with the full numbered
  list in the `[p]` modal. Empty selection renders the empty-state copy. The
  line is a convenience projection — **the gate always recomputes
  independently and never trusts it.**

### The `[p]` 干跑预览 modal

Border-titled 干跑预览 (modal token 60, the `modal-box` family): the dimension
summary, the enumerated cell count, the same-source note
(`同源: pipeline.run_sweep.enumerate_matrix（零复制）`), the composed
`run_sweep.py` LIST argv rendered **verbatim** (data — the shows-the-argv house
precedent), and the collect-all numbered problems list (the gauntlet shape)
when any. `esc` returns. `[p]` also forces an immediate preview-line refresh.

### Region contract

- **Two stacked regions** (the phase-10 data-manager precedent): discovered
  upper (fixed height — title + header + ~2 rows, scrolls), cell table lower
  (flex remainder, scrolls). `─` rules separate; no borders.
- **Discovered pane** (D-03): title `发现的 sweep ({n}) — 默认输出根 + 手动附加`
  with the cadence note right-aligned on the screen title row (`扫描: 前沿 2s ·
  全扫 60s`, D-09 — the note is visible chrome, not a modal). Columns at 120:
  状态 / 输出根 / 规模 / 进度 / ETA; at 80 the 规模 column drops and the state
  glyph+word compresses (glyph carries meaning under NO_COLOR). Discovery =
  scan the default output roots (`pipeline/finetuned` and siblings) plus the
  XDG-persisted manual roots for sweep artifacts. `sweep_manifest.json`
  present ⇒ `○ 已结束`; absent but artifacts appearing/churning (or the TUI's
  own Popen alive) ⇒ `● 运行中`; nothing ⇒ not listed. The ATTACHED sweep
  carries the `◆` marker (accent — Color amendment 13). Progress cells reuse
  the phase-10 progress format verbatim (`{done}/{total}` + 10-cell `█·` bar;
  the bar is additive, never fabricated). Running rows may render a compact
  ETA cell (D-17); unknown-total rows render `总数未知` instead of a fraction.
- **Cell table** (MON-01): title `cell 状态 — {root}` plus the resume note
  (MON-05) right-aligned on the same row. One row per **(model, task)** pair —
  seeds are adjacent COLUMNS (`s42`/`s43`/`s44`, one per configured seed;
  seed-adjacent grouping is the requirement wording). Per-seed cells render
  exactly one state glyph: `◌` queued · `⠋` running · `✓` done · `✗` failed ·
  `⊘` skipped (resume marker). Under `--curve`, each seed cell renders
  `⠋ {done}/{total}` mini-counts over its fraction cells, with per-fraction
  states in `enter` detail. Model/task keys truncate in-cell; full keys in
  detail. Row key = `{model}__{task}` (stable).
- **Stats line** (MON-02 + D-17): 1 row directly above the bottom bar:
  `完成 {done}/{total} · 当前 {model}/{task}/s{seed} · 已用时 {elapsed} · 预估 ≈{eta}`.
  At 80 cols the 当前 segment drops (the running cell is visible in the table).
  Unknown total (CLI-launched, no manifest yet): `完成 {done} · 总数未知 · …
  · 预估 —`. `已用时` accrues continuously from the sweep's earliest
  `run_record.json` `started_at` (`—` before the first record lands).
- **ETA methodology (D-17, contract not implementation):** rolling median of
  completed-cell durations (from each cell's `run_record.json`
  `started_at`/`finished_at` wall-clock; **skipped records excluded** — their
  ~zero duration would bias the median) × remaining cells; per-model median
  where ≥1 cell of that model has completed, global median otherwise; honest
  degradation to `估算中…` until the first completion; when completed-duration
  variance is high the display is a range (`{lo}–{hi}`, min–max) instead of a
  point estimate (the variance threshold is plan-owned — Open Question 4);
  every ETA renders `≈`-prefixed. No ETA when the total is unknown.
- **Scanning discipline** (D-09/MON-01): 2s frontier scan (the live
  model/task/seed region + attached sweep roots) + 60s full scan, all in
  `@work(thread=True)` workers posting run-id-tagged messages (the console
  never freezes); the shared tolerant artifact-loader contract skips
  partially-written JSON with last-known-good retained (never a crash).
  `[r]` triggers an immediate full rescan (toast confirms).

### Attach flow (D-03)

`enter` on a discovered row attaches (the `◆` moves; the cell table + stats +
failures + logs rebind to that root). `[a]` opens the path-input modal
(`PathInputModal` reuse, placeholder `输入输出根路径…`); an invalid path is
never silent (`✗ {path} 不是 sweep 输出根（未发现 sweep 产物）`). Valid manual
roots persist to XDG state (atomic write) and join every future discovery
scan. Attaching a TUI-launched sweep is automatic after launch (D-13).

### `[f]` 失败清单 modal (MON-03/D-11)

Border-titled `失败清单 ({n}) — sweep_failures.json`: one row per failure
(`{model} × {task} × seed_{seed}` — the alias model identity verbatim from the
manifest); `enter` drills into the verbatim `error` string (data, wrapped,
never elided). Empty renders `✓ 无失败 cell`. The modal's own keycaps:
`[r]重跑失败 [esc]返回`. `r` opens the **independent confirmation gate**
(`重跑 {n} 个失败 cell（--from-failures）？— Enter 重跑 / Esc 取消`, the
ConfirmModal vocabulary); confirm routes through the SAME launch pipeline —
env preflight included — composing `run_sweep.py --from-failures
<sweep_failures.json>` (a from-failures enumeration can never match the full
matrix, so the E2' typed gate does not apply to it by construction).

### `[t]` 日志尾随 modal (MON-04/D-10)

Border-titled `日志尾随 — {root}`: a bounded RichLog (wrap + scroll,
max-height 20 family) tailing the sweep's tee file, with the dim tee line
`tee 落盘: {path}` naming the single XDG logs root file (one persistence root,
D-10 — `~/.local/state/dnallmmark/logs/` sibling family; exact filename is
plan-owned). The tee is written by the LAUNCH path (stdout+stderr of the
detached subprocess), so a CLI-launched attached sweep has no tee: the modal
renders the designed unavailable state `无日志可尾随 — 该 sweep 由 CLI 启动,
无 tee 落盘` (honest, never a fabricated empty log). `esc` returns; the tail
stops on close.

### Cell detail (`enter`)

`RowDetailModal` family: full model + task keys, every seed's state, per-
fraction states (`frac_{fraction}: {state}`), and the cell's `run_record.json`
fields verbatim (status, started_at, finished_at, error, peft, metrics keys) —
data, never translated, never elided.

## Cross-Cutting Modals

### The 启动门 (`[enter]` on slot 4 — LNC-01..03, D-02, D-06..D-08, D-13)

The gate is a pipeline, every step blocking, none skippable, all recomputed
fresh (never reading the preview line's cache):

1. **Same-source enumeration** (worker): recompute cells via imported
   `enumerate_matrix` + collect-all validation. Problems ⇒ the numbered
   problems modal (the `[p]` shape), launch blocked.
2. **Env preflight** (D-08): `quick_check.run_quick_check` +
   `env_gate.gate_verdict` (the Phase 8 frozen face, zero changes). FAIL ⇒ the
   env-block modal: `✗ 快检失败: {kernel_names} — 启动已阻断` + the failing
   kernels' detail lines **verbatim** in a bounded RichLog (data) + the route
   hint `[1] 前往环境检查` (digit 1 is the one navigation path — hint only).
3. **Summary confirm** (terraform-style): non-E2' ⇒ ConfirmModal vocabulary —
   `启动 {models} 模型 × {tasks} 任务 × {seeds} 种子 = {cells} cell →
   {output_root}？— Enter 启动 / Esc 取消`.
4. **E2' escalation** (D-02/D-07/LNC-03): when the enumeration covers ALL
   official models × ALL official tasks × ≥3 seeds, the modal escalates to the
   typed-phrase gate (wireframe below). The phrase is **this run's output
   directory name** (final path component), typed in full; `[enter]确认` is
   live ONLY on exact string match (the match check lives in the service, not
   the widget — the UI cannot silently skip it).

```text
                       ┌─ 启动门 ─────────────────────────────────────┐
                       │ ⚠ 全量 E2' sweep — 62 模型 × 50 数据集 × 3   │
                       │ 种子 = 9300 cell → ./finetuned               │
                       │ 需维护者显式授权（LNC-03; 判定与短语校验     │
                       │ 不可绕过）                                    │
                       │                                              │
                       │ 输入本次输出目录名以确认: finetuned          │
                       │ ▏finetune_                                  │
                       │ ✗ 目录名不一致 — 请完整输入 finetuned        │
                       │                                              │
                       │ [enter] 确认（输入匹配后生效）  [esc] 取消    │
                       └──────────────────────────────────────────────┘
```

On the mismatch→match transition the indicator flips to
`✓ 目录名匹配 — [enter] 确认启动` (accent + bold — Color amendment 12).

5. **Launch** (D-06/D-13): spawn `run_sweep.py` as a detached subprocess —
  LIST argv + `PYTHONUNBUFFERED=1` + `start_new_session` (the phase-10 Popen
  discipline; killpg-capable), cwd pinned `pipeline/`, stdout+stderr teed to
  the XDG logs file (D-10). Success ⇒ toast
  `✓ sweep 已启动（分离）— {cells} cell → {output_root} · 跳转任务监控` +
  auto-navigation to slot 5 with the new sweep attached. Spawn failure ⇒
  `✗ 启动失败: {error}`, the modal closes, nothing launched.

### The exit modal (D-06 — app-level `q` intercept)

`q` with a live sweep (TUI-launched Popen alive, or an attached `● 运行中`
sweep) opens ExitModal instead of quitting; with none, `q` quits directly.

```text
                       ┌─ 退出 ───────────────────────────────────────┐
                       │ 运行中的 sweep: 完成 12/36（finetuned）      │
                       │ [enter] 分离退出（默认） · [k] 终止后退出     │
                       │ · [esc] 返回                                 │
                       └──────────────────────────────────────────────┘
```

`enter` = detach (default — the sweep survives; resume-safe by the
`trainer_state.json` marker contract), `k` = SIGTERM the process group then
exit, `esc` = cancel the quit. Three keys, one row, the D-06 triple verbatim.

**Interaction semantics that are contract, not implementation detail:**

1. **Slot 4's selection is the only launch input** (D-01): slot-2 marks are
   never read here; one composition surface, one truth. The selection,
   params, and dirs persist to XDG and reload on mount.
2. **Preview is same-source or it does not exist** (D-05): the service imports
   `enumerate_matrix`/`build_argv` from `pipeline.run_sweep` via sys-path root
   import — zero copied enumeration logic, zero textual imports in services
   (the import-lock test extends). The gate recomputes; the preview line is
   never trusted input.
3. **The E2' boundary is structural, not cosmetic** (D-07/LNC-03): the
   full-matrix verdict and the exact-match phrase check live in the service
   tier; no widget path reaches launch without passing both. The TUI presents
   the gate; it cannot bypass maintainer authorization.
4. **Execution is always a detached subprocess** (D-06): LIST argv +
   `PYTHONUNBUFFERED=1` + `start_new_session`; cwd pinned `pipeline/`; the
   phase-10 killpg discipline backs the exit modal's `k`. Resume safety is the
   `trainer_state.json` marker contract, surfaced as `⊘` + the resume note.
5. **The monitor never blocks** (D-09/MON-01): every scan (2s frontier / 60s
   full) runs in thread workers with run-id-tagged messages; partially
   written artifacts are skipped with last-known-good retained.
6. **Honesty over motion** (the phase-10 progress rule, extended): no
   fabricated totals, percents, ETAs, or log content — `总数未知`, `估算中…`,
   `—`, and the log-unavailable state are designed states, not errors.
7. **One verb, one vocabulary**: `标记` marks anywhere; `附加` attaches (never
   "open"/"load"); `重跑失败` is the from-failures verb; the gate's `确认` is
   confirmation everywhere.

  row clicks select, keycaps are not mouse-only). Focus is always visible:
