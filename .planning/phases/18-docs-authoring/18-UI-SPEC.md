# Phase 18 — UI Design Contract

> Visual and interaction contract for the ONE interactive surface in this phase:
> the **v1.3 milestone test-results HTML report** (18-CONTEXT D18-05..D18-08,
> maintainer-requested 2026-10-22). Generated by gsd-ui-researcher, to be
> verified by gsd-ui-checker.
>
> **Scope ruling.** DOCS-01..04 (`docs/multi-gpu.md`, README/ONBOARDING,
> TUI-DEMO, version surfaces) are **markdown prose deliverables with no UI
> surface** — out of this contract's scope. They follow the gsd-docs-update
> discipline (verified against the codebase) and the TUI-DEMO.md precedent
> shape; D18-01..D04 are ratified and not re-opened here.
>
> The report is a **self-contained static HTML document** (offline-viewable,
> inline `<style>`, system font stack, zero CDN, zero JS framework, no build
> step) that mirrors the dnallm-mark design language as literal inline values —
> family resemblance without a runtime dependency on `css/variables.css`.

### Status vocabulary — badges (the report's core signal system)

Four statuses, each a text badge: **glyph + UPPERCASE word + color** — never
color-only (the NO_COLOR / glyph-redundancy discipline, TUI precedent). Badge
anatomy: 1px border in the status tone, `#FFFFFF`/cream background, 11-12px
600 text in the status tone, padding 2px 8px, radius 4px (`--radius-sm`).

| Status | Glyph | Text tone (contrast on #FFF) | Meaning |
|--------|-------|------------------------------|---------|
| `PASS` | ✓ | `#2F7D0F` (~5.2:1, derived from `--color-success #52C41A` which fails AA at 2.3:1) | Suite/lane green as run |
| `ENVIRONMENTAL-EXCLUDED` | ⚠ | `#8C6300` (~5.4:1, derived from `--color-warning #FAAD14`) | Test excluded for a documented environmental reason (root-chmod class, HF-egress) — reason string mandatory |
| `PENDING-REVIEW` | ◌ | `#0E6EDC` (~4.9:1, derived from `--color-info #1890FF`) | Evidence exists but awaits maintainer review (WINDOWS #50 golden batch) or capture is deferred with a named ticket |
| `FAILED` | ✗ | `#A61D24` (~7.4:1, derived from `--color-error #FF4D4F`) | Known failure (e.g. baseline-member failures if reported) — always paired with disposition text |

Derived text tones are the ONLY new hex values in the document; each exists
because the site's functional token fails WCAG AA (4.5:1) as text on white.
One legend row (all four badges) renders directly under the summary table so
the vocabulary is defined before first use. A missing badge where a status
applies is a spec violation — every evidence row and every figure carries one.

## Page Structure (information architecture)

Recommended home: **`docs/v1.3-test-report.html`** with sibling asset dir
**`docs/report-assets/`** (public docs family; README's docs index at
`README.md:564+` links it; `baseline/` stays internal validation evidence —
D18-05 lets the planner pick `baseline/v1.3-test-report.html` instead; asset
layout is Claude's-discretion per 18-CONTEXT). Content column max-width
1100px, centered; SVG goldens (natural 1480×1024, verified from
`tests/tui/__snapshots__/monitor_running.svg`) render at ~74% natural scale —
readable — inside it.

```text
<header> (not sticky)
  h1: DNALLM-Mark v1.3 Milestone Test Report
  subtitle: 多 GPU 编排与验证 · Phases 13–18 · generated {DATE} · one-line scope
  in-page TOC (anchor links): Summary · 13 · 14 · 15 · 16 · 17 · 18 ·
                              Gap Closures · GPU Evidence · Lanes & Exclusions
<section id="summary">
  verdict line (see Copywriting) 
  Lane summary table + status legend row
<section id="phase-13"> … <section id="phase-18">   (six, uniform shape)
  h2: Phase {N} — {name}          [teal numeral + rule]
  h3 Goal → h3 What Shipped → h3 Evidence → h3 Analysis
  Evidence: suite counts, key test names (code spans), figures where they exist
<aside class="callout callout--gap"> ×2   (teal left border)
  15-04 run_record gap-closure story · 15-05 eval-merge gap-closure story
<section id="gpu-evidence">
  smoke (155 s / 2 cells) + sweep (272 s / 12 cells, dispatch_state done 12/12)
  dispatch_state.json excerpt as <pre> mono block + GPU-run figures
<section id="lanes">
  environmental exclusions detail — one ⚠ ENVIRONMENTAL-EXCLUDED row each,
  reason + scope + link/anchor to source note
<footer>
  Manual-regeneration stamp (verbatim, never a client clock) · static-file
  philosophy note · WINDOWS #50 pending-review note · commit/state stamp
```

### Figure contract (every embedded image, no exceptions)

`<figure>` = `<img>` + `<figcaption>`; the caption carries **two mandatory
lines**: (1) `Figure {N} — {what it is, where captured}`; (2) an analysis line
`Proves: {specific claim}` (bilingual OK: `证明点：…`). Images load from
relative `report-assets/` paths (NOT base64 — D18-05 sanctions relative links;
keeps the HTML diffable and the SVGs greppable). `img { max-width: 100%;
height: auto; }`; SVGs additionally get an explicit readable-width policy
(natural 1480px downscales in-column; never upscale). Every `<img>` has
`alt="{one-sentence description}"` — the TUI SVGs' alt states the screen +
state (e.g. "Monitor screen, running sweep with G lanes and dispatch rows").
Figures whose source goldens are in the uncommitted WINDOWS #50 batch carry a
`PENDING-REVIEW` badge inside the caption (honesty rule — the report never
presents unreviewed goldens as ratified).

### Lane summary table contract (D18-07)

Columns: `Lane | Scope | Result | Status | Notes`. Expected rows (values from
the evidence corpus; the executor verifies counts at generation time, they are
not decorative): pytest full suite (`2236 passed / 6 environmental` baseline),
node lanes (`44/44`), pty byte-silence lane, tier-1 contract pins,
determinism + vendored-stats unmodified. Every row's Status cell carries a
badge; environmental rows repeat the reason in Notes. Numbers are copied from
real gate output pasted at generation time — never typed from memory (the
every-number-is-real rule, report-side).

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| TOC / anchor click | native same-page anchor scroll (`scroll-behavior: smooth` allowed; `:target` needs no JS) |
| Long evidence (full dispatch JSON, logs) | native `<details><summary>` disclosure — zero JS; `summary` carries the caption pattern |
| Everything else | none — there is no second interaction in this document |

**JavaScript: none by default.** If a need emerges at execution (e.g. badge
filter), it must be ≤20 lines inline vanilla JS — but the contract is written
so no JS is needed. No CDN, no frameworks, no build step (hard constraint).

**Print stylesheet (mandatory, small):** `@media print` — `page-break-before`
on each phase `section`, hide the TOC, force `pre` `white-space: pre-wrap`.
A test-results report must print to PDF cleanly.

**Responsive:** single breakpoint at 768px — below it, tables scroll
horizontally inside `overflow-x: auto` wrappers, the content column goes
full-width with 16px side padding, the TOC wraps. No other breakpoints.
