### `baseline/compare.py` (utility, file-I/O transform) — NEW

**Analog (port source):** `/tmp/dnallm-regen/compare_json.py` — the empirically validated comparator from this session's research (UNTRACKED, in `/tmp`, may vanish at any time). Port verbatim, then align with project conventions.

**Port source — full text** (`/tmp/dnallm-regen/compare_json.py`, 59 lines):
```python
"""Order-insensitive recursive comparison of regenerated JSON vs committed JSON.

Reports: missing/extra keys, value type mismatches, exact float diffs,
and float diffs within tolerance (ULP-level noise).
"""
import json
import sys

def walk(a, b, path, diffs):
    if type(a) is not type(b) and not (isinstance(a, (int, float)) and isinstance(b, (int, float))):
        diffs.append(("TYPE", path, f"{type(a).__name__} vs {type(b).__name__}"))
        return
    if isinstance(a, dict):
        for k in set(a) - set(b):
            diffs.append(("MISSING_IN_REGEN" if k in set(a) and k not in set(b) else "", path + "/" + str(k), "key only in committed"))
        for k in set(b) - set(a):
            diffs.append(("EXTRA_IN_REGEN", path + "/" + str(k), "key only in regen"))
        for k in set(a) & set(b):
            walk(a[k], b[k], path + "/" + str(k), diffs)
    elif isinstance(a, list):
        if len(a) != len(b):
            diffs.append(("LEN", path, f"{len(a)} vs {len(b)}"))
        else:
            for i, (x, y) in enumerate(zip(a, b)):
                walk(x, y, f"{path}[{i}]", diffs)
    elif isinstance(a, float) or isinstance(a, int):
        if isinstance(a, bool) or isinstance(b, bool):
            if a != b:
                diffs.append(("BOOL", path, f"{a} vs {b}"))
            return
        if a == b:
            return
        rel = abs(a - b) / max(abs(a), abs(b), 1e-300)
        if rel < 1e-12:
            diffs.append(("FLOAT_ULP", path, f"{a!r} vs {b!r} rel={rel:.2e}"))
        else:
            diffs.append(("FLOAT_BIG", path, f"{a!r} vs {b!r} rel={rel:.2e}"))
    else:
        if a != b:
            diffs.append(("VALUE", path, f"{a!r} vs {b!r}"))

def main(committed_path, regen_path):
    with open(committed_path, encoding="utf-8") as f:
        committed = json.load(f)
    with open(regen_path, encoding="utf-8") as f:
        regen = json.load(f)
    diffs = []
    walk(committed, regen, "", diffs)
    from collections import Counter
    counts = Counter(d[0] for d in diffs)
    print(f"{committed_path.split('/')[-1]}: {dict(counts) if counts else 'VALUES IDENTICAL (order-insensitive)'}")
    for kind, path, detail in diffs[:8]:
        print(f"  [{kind}] {path[:110]}: {detail}")
    if len(diffs) > 8:
        print(f"  ... and {len(diffs)-8} more")

if __name__ == "__main__":
    main(sys.argv[1], sys.argv[2])
```

**Conventions analog:** `script/get_task_performance.py` (stdlib-only, same import style `import os` / `import json`). Align the port with the project's script skeleton — module docstring with purpose + usage (`script/get_task_performance.py:1-26`), `main()` under a config banner, `if __name__ == "__main__":` guard (`script/get_task_performance.py:166-168`). Keep it stdlib-only (runs in any Python ≥3.9; must not require the pandas group). It already takes explicit file paths via `sys.argv` — that is correct: do NOT make it CWD-sensitive like the data scripts.

Known bug in the port source to fix while porting (minor, pre-verified behavior): line 15's conditional `("MISSING_IN_REGEN" if k in set(a) and k not in set(b) else "", ...)` is inside a loop over `set(a) - set(b)`, so the condition is always true — simplify to the constant `"MISSING_IN_REGEN"` (behavior identical; the empty-string branch is dead).
