# Phase 10 — UI Design Contract

> Visual and interaction contract for the data-manager surfaces of the DNALLM-Mark
> terminal console (Textual TUI). Generated by gsd-ui-researcher (tui-design skill loaded,
> D-16), verified by gsd-ui-checker.
>
> **Evolution contract.** This spec **inherits the approved Phase 9 contract**
> (`.planning/phases/09-custom-model-dataset-onboarding/09-UI-SPEC.md`, approved 2026-10-12),
> which itself inherits Phase 8. Inherited verbatim, restated only by reference: the
> **Terminal Contract** (80×24 minimum grid + min-size guard, 120×40 design grid, UTF-8,
> NO_COLOR degradation, keyboard-first/mouse-additive, wide-char discipline), the
> **Navigation Shell** (top menu bar + bottom submenu bar, 1+1 rows, digit nav per base
> screen, one-navigation-path-per-target), the **Spacing Scale** (cell tokens md 4 / lg 8 /
> xl 12 + 1/2-cell exceptions), **Typography** (1 size, exactly 2 weights, hierarchy =
> weight+color+position), the **I18N Contract** (`tui/strings.py` single home,
> Chinese-primary, English technical terms verbatim), the glyph+color redundancy rule, the
> glyph vocabulary (✓ ✗ ⚠ ◆ ◌ ⠋ ◇ …), and the subprocess/thread-worker discipline
> (`@work(thread=True)`, LIST argv, verbatim drill-down, run-id message tags). Where this
> spec amends an inherited list (screen layouts, keyboard map, copy table, accent
> reservations), the amendment is explicit and additive. 10-CONTEXT D-01..D-16 are
> RATIFIED — this spec does not re-open them. Phase mode is `--auto`: every remaining
> would-be design question is recorded in `## Auto-Selected Defaults`.
>
> **Terminal, not web.** No px, no fonts, no hex outside tokens; all dimensions are
> terminal cells; the web leaderboard's CSS is not the design system here.

## The 数据管理屏 (NEW — menu slot 3 becomes real; D-13/D-14 RATIFIED)

A base screen under the Phase 9 shell: top menu bar, bottom submenu bar, digit nav.
Slot 3 loses its `未开放` suffix and placeholder toast — it renders `3 数据管理` in the
active/open vocabulary, `◆`-prefixed when active. Slots 4/5 remain placeholders.
The screen title line / first content row carries `数据管理` + the presence summary.

### Layout (80×24 minimum grid; both bars inherited, content budget = 22 rows)

```text
 ◆ 1 环境检查   2 模型·数据集   3 数据管理   4 运行配置 (未开放)   5 任务监控 (未开放)   6 关于
 ──────────────────────────────────────────────────────────────────────────────────────
 缺失数据集 (3) — 来自 n_audit                                  [z] Zenodo 整包 · 未公开
   数据集                         n_audit 基线行数
   ✗ GUE__emp_H3                       7,349
   ✗ mouse__DMS                        12,411
   ✗ plant__vista-100m                 64,350
 ──────────────────────────────────────────────────────────────────────────────────────
 下载队列 (2) — 串行 · 状态持久化于 XDG state
   任务                            状态        进度           行数对账
   GUE__emperven_H3                ⠋ 下载中    42% █████·····    —
   mouse__DMS                      ◌ 待下载    —              —
 ──────────────────────────────────────────────────────────────────────────────────────
 [d]入队 [r]重试 [x]取消 [a]全部入队 [enter]详情 …                          [?]帮助 [q]退出
```

- **Two stacked regions** (auto-default #1): 缺失数据集 upper (fixed height — title +
  header + ~3 visible rows, scrolls), 下载队列 lower (the flex remainder — title +
  table header + rows, scrolls). Section title rows are 1-row Statics (the 1-cell
  exception family); region separation is the existing full-width `─` rule, not borders
  (borders stay reserved for modals).
- **Missing list** (D-13): one row per dataset in the n_audit missing set — `✗` glyph
  (`$error`) + key column (truncates in-cell at the column width; **full key always
  available in row detail** — the UAT 68-char-key lesson) + `n_audit 基线行数` column
  (right-aligned integer, thousands separators, English digits). This table is the `d`
  and `a` target.
- **Queue table** (D-13): columns 任务 / 状态 / 进度 / 行数对账. One row per queue entry
  (dataset-key granularity, D-08). Row key = dataset key (stable). In-cell key truncation
  + full key in detail, same as the missing list.
- **Mismatch banner** (D-07/D-09 — 对账失败醒目横幅, the gauntlet-banner precedent):
  when any queue entry is in the mismatch state, a prominent banner row renders directly
  **under the queue section title** (never silently scrolled away), `$warning` + `⚠`:
  `⚠ 对账不一致 — {key}: n_audit 基线 {n} 行, 实测 {m} 行（不自动删除）` (Copywriting).
  Multiple mismatches render one banner row each, newest last; the banner block scrolls
  with the queue region but the **queue table sorts mismatch rows to the top** (with
  failed rows) so a banner is never unreachable. Glyph+color dual channel: `⚠` carries
  the meaning under NO_COLOR.

### Queue state machine (D-02/D-06 — glyph+color dual channel, exhaustive)

| State | Glyph + color | 状态 cell copy | 进度 cell | 行数对账 cell |
|-------|---------------|----------------|-----------|---------------|
| pending | `◌` dim (`$text-muted`) | `◌ 待下载` | `—` | `—` |
| downloading | `⠋` dim (running family, gauntlet precedent) | `⠋ 下载中` | `{pct}% {bar}` (bar filled cells `$accent`) | `—` |
| done | `✓` `$success` | `✓ 完成` | `100%` (dim) | `✓ {n} 行一致` |
| failed | `✗` `$error` | `✗ 失败` | last known `{pct}%` (dim) or `—` | `—` |
| mismatch | `⚠` `$warning` | `⚠ 对账不一致` | `100%` (dim) | `⚠ {n}≠{m}` |

- **done = landed AND reconciled pass** (the five-state machine is verbatim D-02 —
  landing alone is not done; reconcile-pass is the SC1 presence-flip trigger, D-11).
- **Progress cell** (D-03, auto-default #3): parsed CLI percent as a right-aligned
  4-cell `{pct}%` + one space + a 10-cell bar `█████·····` — filled `█` (`$accent`),
  empty `·` (dim). Unparsed/indeterminate output renders `⠋ …` and never a fabricated
  percent. The percent text is the NO_COLOR-redundant carrier (the bar is additive).
- **Restart recovery is visible** (D-06, DATA-02): on screen mount the queue file is
  read; entries persisted as `downloading` render as `pending` (中断转 pending) with a
  one-line dim status note `上次中断 — 通道将续传`; failed entries persist as failed and
  are re-queueable via `r`.
- **Drill-down** (D-03/D-15, the env-check pattern): `enter` on a queue row opens the
  detail view — verbatim CLI/audit output lines in a scrolling RichLog (data, never
  translated, never elided), plus the full dataset key, download_url (the registry
  authority, D-01/SC1), and per-state metadata. The same min-size guard family as the
  env drill-down.

### Zenodo 整包入口 (D-12 — disabled-until-public, designed now / activates later)

A 1-row Static in the missing-section title row, right-aligned, four probe states
(glyph+color dual channel on every one):

| Probe state | Render |
|-------------|--------|
| probing | `⠋ Zenodo 公开探测中 …` (dim) |
| not public | `[z] Zenodo 整包 · 未公开（探测于 {HH:MM}）` (dim; `z` keycap accent, action disabled) |
| public | `✓ Zenodo 整包已公开 — [z] 整包下载` (`✓` `$success`, keycap accent, actionable) |
| probe failed | `⚠ Zenodo 探测失败: {error}（稍后重试）` (`$warning`; disabled) |

- The probe (URL HEAD/GET against record 19135551) runs in a thread worker at screen
  mount — the console never freezes; the result is **session-memory only** (no persisted
  probe state — auto-default #6).
- `z` while not-public/failed is **never silent**: a toast restating the explanatory copy
  (公开探测说明文案, Copywriting). `z` while public enqueues the bundle as a single
  queue task (D-12: 单任务入队) whose 任务 cell renders `zenodo-19135551（整包）`.
- 公开后激活 requires no later phase (roadmap note): activation is the probe flipping
  state — no UI change needed.

## Keyboard & Interaction Contract (additions to the Phase 8/9 map)

Phase 8/9 bindings carry over. The 数据管理屏 bottom submenu is D-15 verbatim
(`d` 入队 / `r` 重试 / `x` 取消 / `a` 全部缺失入队 / `enter` 详情, right segment `?` `q`).
New:

| Key | Surface | Action |
|-----|---------|--------|
| `3` | base screens | 数据管理 — now a real screen (placeholder toast removed) |
| `d` | 数据管理 missing list; 选择屏 datasets table (missing rows) | enqueue the cursor's dataset key (queue service; toast). No-op-with-toast on present rows; not bound on the models table |
| `a` | 数据管理 missing list | enqueue **every** missing dataset key (D-15 enqueue-all-missing); toast carries the count |
| `r` | 数据管理 queue table | re-queue the cursor's entry — enabled for `failed` and `mismatch` rows; other states no-op with toast `仅 失败/对账不一致 项可重试` |
| `x` | 数据管理 queue table | 取消 the cursor's entry — **ConfirmModal** (destructive list): pending entries remove from the queue; downloading entries additionally SIGTERM the subprocess (the channel's own resume retains partials — D-06; copy says so) |
| `enter` | 数据管理 queue table | drill-down detail: verbatim CLI/audit output, full key, download_url (D-03) |
| `g` | 数据管理, cursor on a `mismatch` row (and inside its detail) | 重新审计 — rerun the audit leg for that dataset and refresh the row + banner (D-07/D-10 baseline refresh; auto-default #7) |
| `z` | 数据管理 (Zenodo line) | public → enqueue the bundle as one task; not-public/failed → explanatory toast (never silent) |
| `esc` | drill-down detail | return to the screen (inherited; never quits the app) |

**Interaction semantics that are contract, not implementation detail:**

1. **The registry `download_url` is the only download authority** (D-01/SC1) — no URL
   is typed, pasted, or stored anywhere in the UI; the drill-down displays the registry
   value read-only. The TUI composes the modelscope CLI argv from it (LIST argv shown
   in detail — binding constraint 5's shows-the-argv spirit).
2. **Serial queue** (D-04): exactly one entry in `downloading` at a time; `d`/`a`
   appends pending entries — the queue advances itself, no manual start key.
3. **Workers own all subprocess I/O** (D-02/SC5): spawn/reap/parse in
   `@work(thread=True)` workers posting per-item messages with run-id tags (WR-02 —
   async results cannot cross entries); the console never freezes; no in-process
   download ever.
4. **Credentials are zero-touch** (D-01/SC5): no credential is stored in the queue
   state, rendered in any copy, or echoed by the UI; the drill-down renders CLI output
   verbatim (data) and the queue-file schema carries no credential field — the UI
   contract inherits the service invariant and adds no credential surface of its own.
5. **Mismatch never auto-deletes** (D-07): the mismatch state is terminal-for-the-row
   until the operator acts (`r` retry, `g` re-audit, or accepts and leaves it); the
   banner copy names the 不自动删除 rule.
6. **Presence flips exactly on reconcile-pass** (D-11/SC1): selection table ✗→✓ and the
   env-check dataset items update from the same service event; a landed-but-mismatched
   dataset does **not** flip presence (the number would be wrong — the core value).
7. **Queue persistence is the restart story** (D-05/D-06): state lives in
   `~/.local/state/dnallmmark/download_queue.json` (XDG state root, `DNALLMMARK_TUI_STATE_DIR`
   injectable — the env-check state sibling); atomic writes (tmp + os.replace);
   `downloading`→`pending` on load, with the visible 中断 note.
8. **`d` is enqueue, not download** — the label is `入队` everywhere; one vocabulary
   for the same action on both screens (the one-path discipline generalized to verbs).
