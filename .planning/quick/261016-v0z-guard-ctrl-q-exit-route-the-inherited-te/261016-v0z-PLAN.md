Guard the console's inherited exit keys and add the maintainer-ordered quit confirmation. Two rulings combine: the original brief (2026-10-16, ctrl+q is an inherited Textual default that must never bypass the live-sweep kill-and-quit guard) and the mid-planning scope addition (退出的时候要确认，不能一按q就直接退出了 — q must ALWAYS confirm before exiting, even with no live sweep).

Purpose: no key combination kills the console without an explicit operator confirmation; the exit surface is declared, guarded on every path, and documented in the help modal.
