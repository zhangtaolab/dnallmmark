2.1 微调管线（pipeline/）— v0.7.1 奠基，v1.3 强化

模型×数据集微调引擎

  • 41 个 DNA LLM × 50 数据集注册表（models_info.json / datasets_info.json）
  • 动态 batch（序列长度分档封顶阶梯，2026-10-23 内存校准：32/16/8/4/2/1 @ 128–2560 tok）
  • 梯度累积补偿：有效 batch 跨数据集统一（micro 按显存适配）
  • 断点续跑（trainer_state 标记）+ 失败隔离（单 cell 失败不阻塞矩阵）

FLOPs 计量

  • 逐架构前向钩子（Attention/GQA/BigBird/Hyena/Mamba/Mamba2/Caduceus/Enformer 等 ~20 种）
  • 每 cell 产出 flops_report.json（schema 校验）

多 GPU 调度（v1.3 核心）

  • run_sweep_shard.py --mode dispatch：编排器 + 每 GPU 一 worker
  • O_EXCL 台账认领、陈旧 claim 自动重排、--rerun-failed 补跑通道
  • 18 参数高级透传族（ADVANCED_TRAIN_FLAGS，字母序定序）
  • 双卡实测：93-cell 矩阵运行中，0 OOM
